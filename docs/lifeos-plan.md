**What you'll get:** A private LifeOS whose own brain remembers and plans your life, with a voice-first iPhone client and OpenClaw-connected channels/workers that cannot become the source of truth.

**Why this approach:** Life Engine owns state and authority; OpenClaw stays an upstream-compatible integration fabric. Voice is a portable conversation interface, not an approval bypass or channel-specific feature.

**What it will NOT do:** It will not patch OpenClaw core, silently replace the iPhone side button, continuously listen in the background, or grant browser/computer/money/irreversible-action autonomy without a separate authority gate.

**Effort:** XL
**Risk:** High - realtime voice, personal data, upstream integration, and consequential scheduling/action boundaries.
**Decisions to sanity-check:** relay-first voice transport; Google Calendar first; no general browser/computer worker until its separate gate.

## Scope
### Must have
- Owned Life Engine remains canonical for life state, memory semantics, authority, audit, proposals, approvals, execution and conversation state.
- Owned iPhone client provides public-API invocation fallbacks, push-to-talk, streaming voice, text, approvals, timeline, quest/status, notifications, and degraded capture. Every gesture routes through `InvocationAdapter → StartVoiceSession`; a future system-level/side-button adapter must be addable without changing Voice Session or Conversation API semantics.
- Versioned Conversation / Interface API maps user/device/channel identities, ordering, transcript events, cancellation and resume across all adapters.
- OpenClaw is pinned, plugin/adapter-only Integration Fabric for channels, devices, Codex, and external runtimes.
- Full Life Engine: goals→quests→tasks, deterministic priority/constraint scheduling, preview/apply/replan, energy, memory, delegation and authority modes.
- Schedule resolution rule: the internal Life Plan accounts for every minute; Calendar projection consolidates adjacent activities into human-readable blocks whenever it preserves meaning, transitions, deadlines, and actionable guidance.
- Capability Graft Matrix records donor revision/license/reuse mode/owner/security decision for every subsystem.
- Architecture lock: macOS-hosted Python Life Engine service with SQLCipher state; versioned HTTPS/WebSocket Conversation API; iOS SwiftUI client; OpenClaw plugin sidecar uses only mTLS-authenticated adapter calls. Interpretation uses an OpenAI structured-output adapter that returns a schema-validated capture proposal; deterministic code alone mutates canonical records or plans.
- Initial distribution is private, single-user, noncommercial/personal. Allowed copied-code licenses: MIT/Apache-2.0 after NOTICE/SBOM review; review-required: LGPL/MPL; prohibited: unknown, GPL/AGPL, source-available/restricted licenses, including n8n embedding. 
### Must NOT have (guardrails, anti-slop, scope boundaries)
- No OpenClaw core patches, canonical records in OpenClaw, arbitrary provider tool exposure, current unsupported side-button replacement, background continuous recording, or channel-derived authority. Current platform limits do not remove the future side-button `InvocationAdapter` requirement.
- No autonomous money, destructive/irreversible action, unrestricted computer/browser work, or medical diagnosis/treatment; all consequential operations use payload-bound approval, audit, expiry, idempotency and rollback/reconciliation.
- No n8n embedding/distribution without license review; no archived Letta V1; no copied donor code without provenance/license review.
- Initial supported iOS matrix: iOS 17–17.6 iPhone 12/13 (push-to-talk, App Intent/Shortcut, Back Tap); iOS 17–17.6 iPhone 15 Pro/Pro Max (plus Action Button); iOS 18+ iPhone 15 Pro/Pro Max (plus Control Center control); iOS 17+ eligible device (Lock Screen widget/deep link); Siri is tested only as App Intent registration, not automated speech invocation. Simulator automation tests shared handlers, permission denial and UI. Device-targeted XCTest via `xcrun devicectl` on the paired physical test iPhone checks registration/configuration and app deep-link receipt; it does not claim to synthesize hardware button/Back Tap/Siri gestures. No feature may claim runtime gesture support without manually installed, captured device evidence in a later release gate.

## Success criteria
- LifeOS is independently operable if OpenClaw is unavailable: canonical state, conversations, plans, approvals and iPhone client remain functional; only fabric channels/workers degrade.
- A public iOS entry point creates a low-latency continuous conversation that supports partial speech, barge-in, cancellation, cross-device resume and spoken response without bypassing policy.
- The deterministic planner produces explainable minute-level proposed schedules, applies only owned/approved Calendar changes, and replans safely when life changes.
- Life Engine links long-term dreams through quests/tasks to daily blocks; energy and actual outcomes create consented, correctable, confidence-qualified learning.
- Every adapter/worker has typed contracts, capability boundaries, provenance, approval/audit/recovery evidence and an upstream/license compatibility record.
